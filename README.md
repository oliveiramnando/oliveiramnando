## What I've built

- **[tcp-chat](https://github.com/oliveiramnando/tcp-chat)**: End-to-end encrypted chat in C++20. Custom framed TCP protocol, Ed25519 identities with challenge-response login, signed X25519 handshakes, and XChaCha20-Poly1305 messaging. Tested under ASan/UBSan with CI on Linux and macOS.
- **[LeetNode](https://github.com/oliveiramnando/LeetNode)**: Social platform for LeetCode users with profiles, a submission feed, leaderboards, and streaks. Next.js, Express, MongoDB, GitHub OAuth. [Live demo](https://leetnode-nine.vercel.app/)
- **[FinWiz](https://github.com/bucs445fall2025/FinWiz)**: Personal finance dashboard that aggregates accounts through Plaid and runs Monte Carlo portfolio simulations. Express, FastAPI, MongoDB, Nginx, Docker Compose. Team project; I led the backend.
