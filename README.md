## What I've built

- **[tango-chat](https://github.com/oliveiramnando/tango-chat)**: End-to-end encrypted chat in C++20. Custom framed TCP protocol, Ed25519 identities with challenge-response login, signed X25519 handshakes, and XChaCha20-Poly1305 messaging. A custom load generator found 7 concurrency bugs; fixing them raised throughput 420× ([benchmarks](https://github.com/oliveiramnando/tango-chat/blob/main/docs/benchmarks.md)). 64 tests under ASan/UBSan in CI on Linux and macOS.
- **[LeetNode](https://github.com/oliveiramnando/LeetNode)**: Social platform for LeetCode users with profiles, a submission feed, friend leaderboards, group streaks, and topic-based problem recommendations. Next.js, Express, MongoDB, GitHub OAuth. [Live demo](https://leetnode-nine.vercel.app/)
- **[FinWiz](https://github.com/bucs445fall2025/FinWiz)**: Personal finance dashboard that aggregates accounts through Plaid and runs Monte Carlo portfolio simulations. Express, FastAPI, MongoDB, Nginx, Docker Compose. Team project; I led the backend.
- **[LeetCode Share](https://github.com/oliveiramnando/leetcode-results)**: Chrome extension that turns your LeetCode attempts into a shareable, Wordle-style result.
